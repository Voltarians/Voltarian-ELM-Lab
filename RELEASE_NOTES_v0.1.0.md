# Voltarian ELM Lab v0.1.0

First public MVP release of the open-source Android ELM327 emulator and iOS companion project.

## Android application

- Stateful ELM327-compatible command engine
- TCP adapter server on port 35000
- Automatic Bonjour/mDNS service advertising
- Common ELM AT commands and standard OBD-II PID responses
- Configurable VIN, speed, RPM, coolant temperature and voltage
- Voltarian remote profile commands
- Android 8.0 and newer support

## iOS companion source

- SwiftUI iPhone and iPad client
- Automatic local-network discovery
- Manual ELM command terminal and transcript
- Adapter smoke test
- Remote simulated-vehicle controls

## Safety scope

This release is a test emulator. It is not safety-certified vehicle equipment and does not provide direct vehicle programming functionality.
